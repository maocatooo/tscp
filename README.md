# tscp

**把本地文件拖进终端窗口，就能传到远程服务器的指定目录里。**

用 `scp` 得先记住远端路径，开图形化 SFTP 客户端又要重新连一遍、一层层找目录。tscp 是一个终端里的小工具（TUI）：登录后用方向键浏览远程目录、选好目标位置，然后把本地文件（或整个文件夹）**拖进终端窗口**，或者复制后按 `v` 加入队列，再按 `u` 就开始上传。服务器上不需要装任何东西，只要有 SSH/SFTP 就能用。

界面是上下两栏，上面是远程目录，下面是上传队列（示意）：

```
● tscp ▸ root@10.10.10.3        上传目标目录: /opt/app
┌─ 远程目录 ───────────────────────────────────────┐
│ ▸ logs/     backups/     config/                 │  ↑↓ 选择 · → 进入 · ← 返回 · m 新建
└──────────────────────────────────────────────────┘
┌─ 上传队列 ───────────────────────────────────────┐
│ ▸ app.tar.gz  → /opt/app/app.tar.gz      等待     │
│   screenshot_20261113.png → /opt/app/…   ✔ 完成   │
└──────────────────────────────────────────────────┘
 ↑ app.tar.gz 42%  1.2 MB/s  ███████░░░░░░
 已添加 2 个文件, 上传目标目录 /opt/app (按 u 开始)
 拖拽/粘贴路径 · 复制文件/截图后按 v 入队 · u 上传 · a 自动上传 · Tab 切换 · q 退出
```

## 它能做什么

- **先看再传**：在 TUI 里浏览远程目录、按 `m` 直接新建目录（支持 `logs/2026` 多级），不用提前记住路径
- **入队方式多**：拖拽文件/文件夹、资源管理器 `Ctrl+C` 复制文件后按 `v`、截图后按 `v`（自动转 PNG）、粘贴路径文本或 `Ctrl+V`
- **整个目录**：按 `scp -r` 语义展开，保留目录名，远端自动创建子目录
- **两种节奏**：`u` 手动开始上传，或 `a` 开启自动上传（入队即传、一批传完自动续传剩余），带进度、速度和成功/失败状态
- **登录简单**：密码、默认私钥（`~/.ssh/id_*`）、`-i` 指定私钥都支持；带口令的私钥会提示输入
- **会记事儿**：记住上次目标机和每台机器最后浏览的目录，下次启动直达；自动上传开关也记住（不存密码）
- **轻**：SSH 短连接——校验、浏览目录、每批上传各自临时建连，用完即断，不常驻
- **跨平台**：Windows / Linux / macOS 预编译二进制，WSL 剪贴板兼容

## 安装

### 方式一：一行命令，免安装（推荐）

```bash
npx --yes maocatooo/tscp -u root@10.10.10.3 -p '你的密码'
```

也就是 `npx maocatooo/tscp …`，`--yes` 只是跳过首次的 `Ok to proceed? (y)` 确认。这条命令直接从 GitHub 仓库 `github.com/maocatooo/tscp` 拉取并运行，**不用事先安装 tscp，也不用装 Go**：

- 前提只有 Node.js ≥ 14（自带 npx），首次运行需要能访问 GitHub（部分环境会调用 git）；
- 仓库里带了各平台的预编译二进制，启动器会按当前系统自动挑一个；
- `-u` / `-p` / `-i` / `-P` 等参数原样透传给 tscp，`npx --yes maocatooo/tscp -h` 可看帮助；
- 首次下载后走 npx 缓存，之后启动很快。

> npx 拉的是 **GitHub 默认分支**上的版本，不是本机工作目录；改完代码要重新编译并 push 才会生效（见文末「维护者：编译与分发」）。

### 方式二：全局安装，之后直接敲 `tscp`

```bash
npm i -g maocatooo/tscp
tscp -u root@10.10.10.3 -p '你的密码'
```

### 方式三：Go 安装 / 直接拿二进制

```bash
go install github.com/maocatooo/tscp@latest    # Go >= 1.26, 或开启 GOTOOLCHAIN=auto 自动切换
```

不想装任何东西，也可以直接下载仓库 `binaries/` 下对应平台的可执行文件运行。已提供：
`windows-amd64`、`linux-amd64`、`linux-arm64`、`darwin-amd64`、`darwin-arm64`。

## 快速上手

以密码登录为例，一条命令启动：

```bash
npx --yes maocatooo/tscp -u root@10.10.10.3 -p '你的密码'
```

1. **连接校验**：先临时连一次 SSH 验证账号并取回家目录，随后进入 TUI，连接随即断开。
2. **选目标目录**：`↑/↓` 移动，`→` / 回车进入，`←` 返回上级；没有合适的目录就按 `m` 新建（支持多级，创建后直接进入）。
3. **把本地文件加入队列**，任选一种：
   - 把文件或整个文件夹从资源管理器**拖进终端窗口**；
   - 在资源管理器 `Ctrl+C` 复制文件 → 状态栏提示"检测到 N 个文件" → 按 `v`；
   - `Win+Shift+S` / QQ / 微信 / Snipaste 截图 → 按 `v`，自动存成 PNG 入队；
   - 复制一段路径文本，在终端里 `Ctrl+V` 粘贴，或直接按 `v` 读剪贴板。
4. **上传**：按 `u` 把队列里的文件传到当前远程目录，界面显示进度、速度和每项结果。想"丢进去就自动传"，按 `a` 打开自动上传（再按 `a` 关闭）。
5. **收工**：`q` 或 `Ctrl+C` 退出。

下次连同一台机器可以省略 `-u`（用缓存的上次目标）；用私钥登录连 `-p` 都能省：

```bash
tscp                                             # 上次目标 + 默认私钥, 直达上次浏览的目录
tscp -u root@10.10.10.3                          # 自动尝试 ~/.ssh 下的默认私钥
tscp -u deploy@10.0.0.9 -i ~/.ssh/id_ed25519     # 指定私钥; 非 22 端口加 -P 2222
```

> 下面例子里的 `tscp` 指安装后得到的命令；只用 npx 的话，把 `tscp` 换成 `npx --yes maocatooo/tscp` 即可，参数完全一样。

## 命令行参数

| 参数 | 说明 |
| ---- | ---- |
| `-u` | 目标机 `user@host`；user 省略时默认 `root`，整体省略时用缓存的上次目标（含端口） |
| `-p` | 登录密码；与证书至少提供其一，两者都有时**证书优先、密码兜底** |
| `-i` | 私钥文件；省略时自动尝试 `~/.ssh/id_ed25519`、`id_ecdsa`、`id_rsa` |
| `-P` | SSH 端口，默认 22 |

密码含特殊字符记得加引号；命令行传密码会留在 shell 历史里，介意就改用私钥。

## 按键速查

| 按键 | 作用 |
| ---- | ---- |
| `↑/↓`（或 `k/j`）、`g/G` | 移动光标 / 跳到首尾 |
| `→` / `l` / 回车 | 进入远程目录 |
| `←` / `h` / `Backspace` | 返回上级 |
| `r` / `m` | 刷新目录 / 新建远程目录（支持多级 `a/b`，`/` 开头为绝对路径，创建后进入） |
| 拖拽文件到终端窗口 | 终端把路径作为字符送入，自动识别加入队列 |
| `Ctrl+V` / `v` | 读取剪贴板（文件列表 / 截图 / 路径文本）加入队列 |
| `Tab` | 在目录列表 / 上传队列之间切换焦点 |
| `x` / `Delete` | 移除队列里选中的项（焦点在队列时） |
| `c` | 清空队列（上传中不可用） |
| `u` / `a` | 立即上传 / 自动上传开关（入队即传，状态会记住） |
| `q` / `Ctrl+C` | 退出 |

在资源管理器复制文件或截图后，程序只会在状态栏**提示**，不会自动入队，需按 `v` 确认。

## 目录缓存

`~/.tscp/cache.json` 记录上次的目标机（`-u`）和每台机器上最后浏览的远程目录：

- `-u` 省略时自动使用上次的目标（含端口），此时只需 `tscp -p password`；
- 启动时直接进入该目标机上次浏览到的目录（目录已不存在则回家目录）；
- 自动上传开关（`a`）的状态也会记住；
- 删除 `~/.tscp/cache.json` 即可重置；登录密码不会缓存；
- 可用环境变量 `TSCP_CACHE_DIR` 覆盖缓存目录位置。

## 注意事项

- **安全性**：主机指纹未校验（`InsecureIgnoreHostKey`），适合内网/测试环境，公网使用请自行加 known_hosts 校验。密码通过命令行参数传入会进 shell 历史；带口令的私钥会在启动前提示输入（隐藏回显），不支持 ssh-agent。
- **连接模型**：不保持长连接，启动校验、浏览目录、每批上传各自临时建连、用完即断；上传走 SFTP，按队列顺序逐个传，同一批共用一条连接。
- **拖拽 / 粘贴**：Windows 终端（Windows Terminal / conhost）把拖入文件的路径作为一串按键字符送入，程序累积后整体识别（支持带引号、空格、多文件）；`Ctrl+V` 常被终端拦截转为粘贴输入，同样会被识别为路径入队。
- **截图上传**：剪贴板里的图片按 `v` 保存成 `%TEMP%\tscp\screenshot_时间戳.png` 再入队。Windows 下优先取截图工具提供的 "PNG" 格式，只有 DIB 位图时才本地转码为 PNG（支持 1/4/8/16/24/32 位、调色板、alpha 掩码、自顶向下等形态），**不会产出 BMP**。
- **复制文件检测**：程序每 0.5 秒检查一次剪贴板序号，复制文件后状态栏提示"检测到 N 个文件 — 按 v 加入队列"，复制普通文本无提示。
- **WSL**：剪贴板通过 Windows interop 调 `powershell.exe Get-Clipboard` 读取（能拿到资源管理器复制的文件列表，截图经 `-Format Image` 转存为 PNG），Windows 路径自动转成 `/mnt/c/...`；拖拽进终端的 `/mnt/...` 路径同样可识别。需启用 WSL interop（默认启用），复制文件的轮询检测在 WSL 不可用，按 `v` 手动读取。

## 维护者：编译与分发

仓库根目录本身就是 npm 包：`package.json` + `bin/tscp.js` 启动器 + `binaries/` 全平台预编译二进制（`files` 白名单在发布到 npm 时排除 Go 源码；从 GitHub 直跑会拉整个仓库）。主分发方式是 **GitHub 直跑**，不必发 npm：

```bash
# 发布前先重新编译所有平台(产物进 binaries/), 然后提交推送
build.cmd
git add . && git commit -m "update binaries" && git push

# 本地模拟用户流程验证
npx --yes -p . tscp -u root@10.10.10.3 -p password
```

可选：也可以发布到 npm registry。公共源上 `tscp` 名字已被他人占用，故用带 scope 的 `@maocat/tscp`（scope 必须是自己的 npm 用户名或组织名；发布需账户开启 2FA）：

```bash
npm publish --access public     # 按 OTP 提示输入验证码
```

从源码编译（`go.mod` 要求 go >= 1.26，本机 Go 版本较低时执行 `go env -w GOTOOLCHAIN=auto` 让工具链自动切换）：

```bash
git clone https://github.com/maocatooo/tscp.git
cd tscp
go build -o tscp .     # 当前平台
go test ./...          # 单元测试
build.cmd              # Windows 下编译全平台二进制(输出到 binaries/, 供分发)
```
